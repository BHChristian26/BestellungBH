# BestellungBH – Render Root Version

This version is intentionally flat so that all files can be uploaded directly to the root of the GitHub repository.

Files:
- index.html
- server.js
- package.json

Render settings:
- Language: Node
- Root Directory: leave EMPTY
- Build Command: npm install
- Start Command: npm start
- Health Check Path: /

Environment variables:
- ADMIN_USER = your login name
- ADMIN_PASSWORD = your password
